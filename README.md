# Распознавание рукописных символов и фигур

Веб-приложение для распознавания рукописных букв, цифр, фигур и знаков прямо в браузере — без сервера, вся модель работает локально через ONNX Runtime Web.

🔗 **Демо:** (https://dildemuratov.github.io/handwriting-recognition/)

## Возможности

- **Буквы и цифры** — распознавание символов латиницы, кириллицы и цифр
- **Фигуры и знаки** — распознавание 20 классов: круг, квадрат, звезда, стрелки, галочка и др.
- **Топ-5 вариантов** с вероятностями после распознавания
- **Улучшение рисунка** — кнопка «✨ Улучшить» плавно выравнивает нарисованный символ или фигуру
- Тёмная / светлая тема, история последних 5 распознаваний

## Как это работает

**Модели.** Свёрточные нейросети (CNN) обучены в Google Colab на PyTorch и экспортированы в формат ONNX (opset 14). Инференс полностью выполняется в браузере через ONNX Runtime Web — без обращения к серверу, все вычисления локальные.

**Улучшение рисунка.** Реализовано без нейросети, чисто алгоритмически на JavaScript:
- рисунок записывается как набор штрихов (точек, по которым двигалась мышь);
- каждый штрих передискретизируется на равномерную сетку точек;
- применяется сглаживание (скользящее среднее по нескольким проходам) — убирает дрожание руки;
- лёгкая коррекция наклона (shear) для букв и цифр;
- итоговый контур вписывается обратно в исходные габариты рисунка;
- переход от исходного рисунка к улучшенному анимируется плавной интерполяцией точек (easing-функция, requestAnimationFrame) — линии на глазах выпрямляются, а не просто заменяются.

## Технологии

- PyTorch → ONNX
- ONNX Runtime Web
- Vanilla JS, HTML5 Canvas
- Google Colab (обучение моделей)

## Запуск локально

Открыть `index.html` напрямую нельзя (браузер блокирует загрузку файлов модели по протоколу `file://`). Нужен локальный сервер:

```bash
python -m http.server 8000
```

Затем открыть `http://localhost:8000` в браузере.
